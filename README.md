# 帝愛グループ決戦：１７歩 (Jūnana-Ho) Simulator

「賭博黙示録カイジ」に登場する究極の心理麻雀ゲーム**「17歩（じゅうななほ）」**を再現したブラウザゲームアプリケーションです。

## 特徴
- **カイジの世界観を再現：** 黒を基調としたダークなUI、金と赤のアクセント、ドラマチックな「ざわ… ざわ…」アニメーション演出。
- **多彩なプリセット：** 「タンヤオ型」「清一色型」「国士無双型（役満）」から手軽に構築して対局を開始できます。
- **全17巡の頭脳戦：** プレイヤーと村上（帝愛）が交互に山からツモり、ロンやツモ、流局までの緊迫した勝負を楽しめます。

## 遊び方
1. `index.html` ファイルをダブルクリックするか、ブラウザ（Chrome / Edge / Firefox 等）にドラッグ＆ドロップして開きます。
2. タイトル画面の「対局開始」をクリックします。
3. 牌構築フェーズでお好みの型（プリセット）を選択し、「勝負開始」を押します。
4. バトル画面で「ツモる」を押し、ツモあがりやロンを狙って勝利を掴んでください！
